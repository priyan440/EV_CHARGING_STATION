# EV Charging Station Management System

A modern, responsive Electric Vehicle Charging Station web application built with React, Vite, Tailwind CSS, and Lucide React.

## Features
- **Multi-role Dashboards**: Admin, Manager, Technician, Security, and Customer views
- **Slot Booking**: Real-time EV slot availability & reservation
- **Smart Theme & Cyber UI**: Sleek glassmorphism and modern dashboard aesthetics
- **Interactive Metrics**: Live station status, power usage, and transaction history

## Getting Started

### Prerequisites
- Node.js (v18+)
- npm

### Installation
```bash
npm install
```

### Development
```bash
npm run dev
```

### Build
```bash
npm run build
```
